- Debian 12、Docker 和更早版本升级未完成本轮真机验收；旧系统、ARM、跨部署模式迁移和 Docker 外部 DB 不在已验证范围。
- 整机快照已创建但完整回滚未验收；配置/数据恢复不替代程序、服务定义、系统盘/数据盘和安全组回滚。
- 移动端 Relay 表格溢出，Token 重置、跨进程写入、历史孤儿及其它既有维护债仍按原范围保留，不宣称已解决。
- 已发出的日志包含凭据，需限制传播并另行安排更换；此次未执行凭据或服务器配置变更。
